## Learning Path

A practical progression through these **CTF labs**:

1. Begin with **Tomcat Trap: Lab Setup** to understand the lab environment.
2. Continue with **Netdiscover Target Hunt** to practice network discovery.
3. Explore **Tomcat Trails** and **Tomcat Manager Warpath** for Tomcat-focused reconnaissance.
4. Move through **Tomcat Takedown** and **Tomcat to Root** for progressively deeper Tomcat security scenarios.
5. Study **Thales Perspective** for an additional investigation-oriented challenge.
6. Start the LupinOne sequence with **LupinOne: Hidden Key Heist**.
7. Continue with **Empire Lessons: LupinOne** and **LupinOne: Key to the Empire**.
8. Use **LupinOne Detection Lab** to develop a defensive investigation perspective.
9. Finish with **LupinOne: Key to Root** for a root-focused challenge.

Difficulty levels are not inferred unless explicitly stated in the supplied lab information.

## How to Use the Labs

1. Open a lab using its direct link.
2. Review its objectives and environment requirements.
3. Work only within the provided CTF or an explicitly authorized environment.
4. Perform reconnaissance before attempting access or escalation.
5. Record relevant services, files, credentials-related findings, keys, permissions, and configuration details.
6. Analyze why each weakness matters from both offensive and defensive perspectives.
7. Document detection opportunities and remediation ideas where applicable.
8. Keep all testing limited to systems you are authorized to assess.
